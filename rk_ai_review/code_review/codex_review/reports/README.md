# 내부 검증 자료

이 디렉터리는 팀 공유용 본문이 아니라 감사·재현·원문 보존용이다. 일반 리뷰 공유에는 상위
`README.md`와 `최종보고서.md`만 사용한다.

- `E2E_FINDING_WORKSHEETS.md`: 최소 입력과 실행 순서
- `CANDIDATE_AUDIT.md`: 채택·조건부·기각 집계
- `RAW_187_REAUDIT_MAP.md`: 187개 raw 의견의 최신 판정
- `PR_HISTORY.md`: 관련 PR 이력
- `RAW_FULL_REAUDIT.md`: 진행 체크포인트와 coverage
- `<페르소나>_<연차>.md`: 최초 관점별 의견. 파일 첫머리의 재감사 알림을 우선한다.
