- feature 근거/실행 경로: `src/parser/csql_lexer.l:916-918`이 모든 `replication`을 전용 token으로 반환하고, option grammar는 `src/parser/csql_grammar.y:19891-19996`에만 추가됐다.

- 수정·테스트: 비예약/문맥 keyword로 바꾸고 identifier 위치별 회귀 시험.

## USER3-02 — 생성과 HA 시작에 성공한 복합 UK 테이블의 행이 복제되지 않을 수 있다

- 심각도/신뢰도: **High / High**
- feature 근거/실행 경로: 사용자 DDL 검사는 any-NN(`src/object/class_object.c:95-98`, `src/object/schema_manager.c:16115-16129`), DML은 all-NN(`src/base/object_representation_sr.c:4712-4719`, `src/transaction/locator_sr.c:8041-8055`).
- develop 비교/PR: feature 신규; #6798/#7370.
- 재현/불변식: `(a NOT NULL,b NULL,UNIQUE(a,b)) REPLICATION=ON` 생성 후 HA DML. 성공 메시지가 난 ON 테이블은 실제로 복제돼야 한다.
- 수정·테스트: 동일 후보 validator 사용 및 SQL 종단 시험.
