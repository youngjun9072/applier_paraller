# 재구성 검토 항목 (한 번에 훑기용)

재구성하며 판단이 모호했던 곳을 모았다. 각 문서 본문에도 `> [!question] 검토:` 콜아웃으로 같은 표시가 있다. 재구성이 끝난 뒤 한 번에 검토한다.

## 전역
- **파일명·폴더**: `숫자-한글` 폴더 + 하이픈 파일명으로 통일. 이대로 확정?
- **링크**: 지금은 Obsidian 위키링크. GitHub push 직전 표준 마크다운 링크로 일괄 변환 예정.
- **to-ai 코멘트**: GitHub 정리본에서는 전부 제외. 재구성 후 별도 리뷰.

## 4-lsa-홀 (원본 8)
- **코드 분리**: file:line 코드 상세를 `코드-근거.md`로 분리하고 본문은 개념만 남김(CLAUDE.md 규칙). 이 분리 방식 OK?
- **반대 방향 폐기 근거**: "완료 대신 홀을 기록"하는 반대 설계를 왜 안 쓰는지를 본문에 어느 수준으로 남길지.
- **미확인 3건**: ① failback 시 writeset 특화 재초기화 코드 못 찾음(현재 없음 추정), ② 완료집합 상한을 실제로 치는 워크로드 조건 정량 미검증, ③ B4 단기책을 정식 설계에 포함할지(완료 마킹으로 바로 가면 불필요).
